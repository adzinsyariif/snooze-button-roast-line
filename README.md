Entry for the [Snooze Button Roast](https://make.fun/c/u-carbon-forge-snooze-button-roast-14cbafc6) bounty on make.fun: a program that writes one line roasting an alarm clock that rings at 6 AM on a Saturday to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```

It writes the entry line to `/output/entry.txt`.
